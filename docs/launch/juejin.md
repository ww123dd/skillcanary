# 掘金发布稿

标题（选一个）

- 为什么你写的 AI 规则越来越没用
- 规则要靠"被加载"才生效，机制不靠

标签：#AI编程 #Agent #提示词工程 #开源

正文：

给 AI 写规则的人迟早会撞上同一堵墙：你以为规则生效了，其实它经常没被读到。上下文太长被裁掉，任务不走那条路，懒加载到需要时已经晚了。**没被加载的规则，和没写过没区别。**

第二堵墙是堆积。规则越沉淀越多，上下文越来越挤，AI 不是越听话，是越难用：注意力被稀释，规则之间开始互相打架。

第三堵墙是模型升级。你为弱模型写的那些"别这么干、必须那么干"，到了强模型身上就成了枷锁。规则约束的是过程，模型越强越被它拖住。

第四堵墙是落实。改完你其实不知道：规则加载了吗，执行了吗，结果是真的还是碰巧。

第五堵墙是"让它记住"。可记住本身也要靠加载和注意力，它还是会漏。

所以问题不该在规则上解决。把每一次翻车变成一道必须通过的题：AI 记不记得住不重要，它必须过了这道题才能合。**规则约束过程，机制约束结果**——模型越强，过题应该越容易。

我做的 SkillCanary 就是干这个的：

- 没有 case 或确定性目标，改动不许合（fail closed）
- 判分靠外部能重算的事实，不靠说明文字，也不把 LLM 的判断当信任根
- 隐藏测试、答案收起、污点扫描：抄答案式通过不算通过
- Pass^k 看稳不稳；三个月后判据漂了，旧结论就作废

    git clone https://gitee.com/review-for-qing-lazy/skillcanary
    cd skillcanary && node bin/skillcanary.js doctor examples/basic-skill
